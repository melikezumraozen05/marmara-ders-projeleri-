# Hafta 3 — Şehir Seçimi

Nesne Yönelimli Programlama 1 dersi için C# Windows Forms uygulaması.

Şehirler çoklu seçilebilir. **button3**, seçilen şehirleri seçim sırasına göre sağdaki listeye aktarır. Seçimi kaldırmak için şehre tekrar tıklanır. **button1** ve **button2** için işlem tanımlanmamıştır.

## Çalıştırma

Windows üzerinde Visual Studio ile `hafta3.csproj` dosyasını açın. .NET Framework 4.7.2 hedefleme paketi ve .NET masaüstü geliştirme bileşenleri kurulu olmalıdır. F5 ile çalıştırın.
